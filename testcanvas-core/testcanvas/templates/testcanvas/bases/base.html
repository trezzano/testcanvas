{% comment %} Centralized HTMX loading spinner controller. Shows the global bottom-right spinner while any HTMX request is in flight and hides it once every request has settled. Robustness notes (why this is not a plain +1/-1 counter): * In-flight requests are tracked in a Set keyed by each request's XHR (falling back to the source element), so overlapping requests are counted correctly and a stray "settle" event can never drive the count negative or desync the indicator. * Events are bound on ``document`` and cover HTMX-swapped content. * A short show-delay suppresses flicker on very fast (localhost) responses, while a minimum-visible window keeps the spinner perceivable once it does appear. * A safety timeout force-clears the indicator if an expected settle event is ever missed (e.g. the triggering element was swapped out of the DOM, so its ``htmx:afterRequest`` never reached us), so the spinner can never get stuck on screen. * Any element (or one of its ancestors) carrying the ``hx-no-spinner`` class opts out. {% endcomment %} {% comment %} Toast behaviour: close on "×" click and auto-dismiss after a timeout.
