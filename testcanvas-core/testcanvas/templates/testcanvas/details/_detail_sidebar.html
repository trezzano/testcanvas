{% load i18n %} {% comment %} Shared detail sidebar shell. Included by both traceability views (graph and RTM table). Replaces the old Bootstrap modal: clicking a US / AC / TC label (RTM) or tapping a node (graph) loads the matching detail partial into ``#detail-sidebar-body`` via HTMX. A small script (detail_sidebar.js) slides the panel in on load and wires the close / re-open controls. The panel can stay open or be dismissed. The panel overlays the RIGHT edge of the content area so both pages share the exact same markup and styles regardless of their own layout. The ``#detail-sidebar-resize`` handle (left edge of the panel) lets the user drag the panel to any width they like. The chosen width is NOT persisted. {% endcomment %}
